# 智能马桶检测管理系统

面向智能马桶生产企业的质量管控平台，覆盖出厂检验、过程检验与型式试验全流程。

## 核心功能

### 1. 登录与权限
- 无状态令牌认证登录，四类角色（系统管理员、质检主管、检测员、生产人员）登录后进入与其权限匹配的界面。

### 2. 质量仪表盘
- 一次交验合格率、累计检测记录、不合格记录、待处理不合格品等关键指标卡片。
- 合格率趋势图、不良项柏拉图、各型号合格率对比、SPC 控制图与 Cpk 过程能力指数。

### 3. 检测任务管理
- 出厂 / 过程 / 型式三类任务，支持派工、领取、状态流转与超期跟踪。
- 任务状态覆盖：待派工 → 待检测 → 检测中 → 待审核 → 已完成（可终止）。

### 4. 检测数据采集与自动判定
- 按产品型号自动套用检测方案，逐项录入实测值。
- 系统依据标准值与上下限阈值自动完成合格 / 不合格判定，超标项实时高亮并展示偏差。
- 支持 Excel / CSV 表格批量导入，可下载导入模板，逐行反馈成功与失败原因。
- 提供检测设备直连上报接口，按检测项编码或名称接收实测值并自动判定。
- 检测记录可上传现场照片留档，详情页直接查看。

### 5. 不合格品闭环处置
- 不合格检测项自动生成不良记录，支持等级划分、现象描述、原因分析、责任部门指派。
- 返工 / 返修 / 让步接收 / 报废处置流程与复检结果回填。

### 6. 报表与质量追溯
- 按批次生成出厂检验报告，含检测明细、不合格项与检验结论，支持在线预览与打印。
- 报告可导出为 Excel 文件（含报告概况、检测记录、检测明细与不合格项四个工作表）。
- 以批次为线索查看该批次全部检测记录与处置情况。

### 7. 基础数据与标准配置
- 产品型号、分类、供应商、生产批次等基础档案维护。
- 检测项库与检测标准库，可为不同型号配置标准值、上下限与判定方法（支持单边上下限）。

### 8. 公告与通知
- 发布质量公告与标准变更通知，重要公告可置顶。

### 9. 用户与角色管理
- 账号增删改查、角色分配、启用 / 禁用与密码重置。

### 10. 操作日志
- 自动记录登录、任务派工与状态变更、检测记录录入与审核、不合格品处置、公告发布、标准调整、账号变更等关键操作。
- 支持按操作类型、操作人 / 内容关键字、日期区间筛选查询，并分页浏览。
- 提供今日 / 近 7 天 / 累计操作量与操作类型分布统计。
- 仅系统管理员与质检主管可见，满足权限隔离与审计追溯要求。

### 11. 消息提醒
- 定时扫描超期任务、超过 2 天未审核的检测记录与未闭环的不合格品。
- 生成站内消息推送给责任人、质检主管与管理员，同一事项 24 小时内不重复提醒。
- 顶部消息中心显示未读数，可逐条或一键标记已读。

## 演示数据
- 内置脚本生成 12 个产品型号、34 个生产批次、360 条检测记录（每条含 13 个检测项）及 16 条不合格品记录。
- 生成 360 条操作日志，覆盖近 30 天 9 类操作，日志页面开箱即有内容。
- 针对合格判定功能提供合格、不合格、边界值三类显式测试用例数据，可通过测试命令一键验证。
